# MILLER Production Instructions

These instructions apply to every agent working in this repository.

## Mandatory first step

Before starting any MILLER production task, read
`docs/MILLER_PRODUCTION_PLAYBOOK.md` in full.

Treat that playbook as the primary production standard for MILLER. Follow its
sequence, approval gates, tool restrictions, and escalation rules. Do not
change an approved production route on your own.

If a user request conflicts with an approved route or skips a required gate,
pause the affected production step, explain the conflict briefly, and ask for
an explicit decision before proceeding.
