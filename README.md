# Visual Production Studio — reference-faithful version

Живой одностраничный HTML/CSS/JS-сайт, собранный по утверждённому референсу.

## Что внутри

- главный экран с кинематографичным горным видеофоном;
- четыре карточки видеоработ: Healthcare, Residential, AURELIA и FMCG;
- услуги и предварительные цены;
- развернутый supporting-блок Patient Plan;
- процесс, блок о студии и финальный CTA;
- полноэкранный видеоплеер и адаптивная мобильная версия;
- полный интерактивный кейс Bali в `cases/bali/`.

## Запуск

Откройте `index.html` или запустите любой статический сервер из этой папки.

## Перед публичным запуском

Форма готовит текст брифа; посетитель отправляет его в MAX самостоятельно. Кликом по MAX и подготовкой брифа можно измерять намерение обратиться, но полученную заявку студия подтверждает в самом MAX.

В публичных медицинских фильмах и Patient Plan бренд скрыт. Брендированный внешний интерактивный проект исключён из навигации. Прежние версии доступны в истории Git: обновление сайта не является удалением истории репозитория или сторонних публикаций.

Инструкция по подключению домена и измерению рекламы: `docs/DOMAIN_LAUNCH.md`.
