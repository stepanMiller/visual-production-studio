# Visual Production Studio — reference-faithful version

Живой одностраничный HTML/CSS/JS-сайт, собранный по утверждённому референсу.

## Что внутри

- главный экран с кинематографичным горным видеофоном;
- четыре карточки работ: VERBA Heart, emotional film, Bali и Patient Plan;
- услуги и предварительные цены;
- развернутый supporting-блок Patient Plan;
- процесс, блок о студии и финальный CTA;
- полноэкранный видеоплеер и адаптивная мобильная версия;
- полный интерактивный кейс Bali в `cases/bali/`.

## Запуск

Откройте `index.html` или запустите любой статический сервер из этой папки.

## Перед публичным запуском

1. Выбрать название и заменить временный wordmark `VISUAL PRODUCTION`.
2. Подключить рабочий email/Telegram к форме.
3. Подтвердить право публичного показа клиентских материалов VERBA.
4. Утвердить цены и состав пакетов.
